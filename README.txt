HOW TO RUN

4. Use Reset Demo Data in Admin to restore the classroom baseline.

FINANCIAL FORMULAS USED
Revenue = Selling Price × Quantity Sold
COGS = Cost Price × Quantity Sold
Gross Profit = Revenue − COGS
Gross Profit Margin % = (Gross Profit ÷ Revenue) × 100
Markup % = ((Selling Price − Cost Price) ÷ Cost Price) × 100
Available Stock = Opening Stock + Restocked Quantity − Quantity Sold
Sell-Through Rate % = Quantity Sold ÷ Total Available-to-Sell Quantity × 100
Inventory Value = Current Available Quantity × Cost Price
Estimated Net Profit = Gross Profit − Operating Expenses
Average Order Value = Revenue ÷ Number of Orders
